# SVG: Data as Art

Minimalist design is not only visual — it is also structural data.

In Wyrlight workflow, SVG (Scalable Vector Graphics) is the core format because it combines:
- geometry
- precision
- scalability
- and long-term readability

---

## Why SVG matters

SVG is not a pixel image.

It is mathematical vector data rendered in real time by the browser or design tools.

This creates several key advantages:

- Infinite scalability without quality loss
- Extremely small file sizes
- Editable structure (code-based graphics)
- Clean version control (text instead of binary files)
- Direct compatibility with automation and AI tools

For Wyrlight, SVG is not a format — it is a working system.

---

## SVG in Wyrlight Workflow

Every design starts as vector geometry.

Even if the final output becomes:
- PNG
- mockup
- or print file

…the source remains structured vector data.

SVG is used as:

- visual prototype format
- reusable design component
- structured data container
- production-ready artwork base
